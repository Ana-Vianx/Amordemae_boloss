### Amordemae_boloss

#Objective
A system where administrators manage production, while other users can only view the menu.

#Project Scop
The project is developed using HTML5 and CSS3 for the front end, Python for the back end, and PostgreSQL for data management.

This application serves as a practical implementation of the knowledge acquired during ongoing studies, aiming to reinforce technical skills and apply theoretical concepts in a real-world scenario
